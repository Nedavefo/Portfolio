03 ai-workflow.md

AI tools such as Claude Code are part of how I build. The speed comes from how I use them, not from accepting whatever they produce.

  1. Spec first

    I define the goal, the data and what "done" looks like before any code is written, so the tool works on a clear target.

  2. Small steps

    I split work into small, checkable changes: one model, one screen, one migration at a time. Errors stay easy to find.

  3. Delegate the repetitive

    Boilerplate, data migrations, test scaffolding, refactors and documentation go to the AI, so my time goes to design and decisions.

  4. Verify everything

    I read every diff, run the code, compare behaviour against the system being replaced and commit through Git. I never ship something I cannot explain.

Used on Sidic Web to rebuild a legacy ERP in Django and PostgreSQL, from schema and data migration to reports and permissions.
