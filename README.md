# Portfolio

My personal portfolio website: who I am, what I work with, and a selection of my projects.

**Live site:** https://nedavefo.github.io/Portfolio/

## Built with

- Semantic HTML5 and responsive CSS (no frameworks)
- Google Fonts (Poppins) and custom SVG icons
- Hosted on GitHub Pages and deployed automatically with GitHub Actions

## Run locally

It is a static site, so just open `index.html` in a browser, or serve it:

```bash
npx serve .
```
